(f) Apply cross-validation to the training set in order to determine the optimal tree size.

# In decision tree, especially unpruned ones, the model can grow very deep and create many splits to fit the training data perfectly.
# this will lead to overfitting, to avoid, we use cost complexity pruning parameter, where it minimizes loss function

import numpy as np
import matplotlib.pyplot as plt
from sklearn.model_selection import cross_val_score

# Getting effective alphas and corresponding tree impurities
path = tree_model.cost_complexity_pruning_path(X_train, y_train)#applying cost-complexity pruning to determine the optimal tree size
#ccp_alphas Controls how much penalty given to tree complexity
ccp_alphas = path.ccp_alphas #tree would prune a split

trees = []
#looping over, for each one creating new decision tree that uses pruning strength and trains the tree
for alpha in ccp_alphas: 
    clf = DecisionTreeClassifier(random_state=1, ccp_alpha=alpha)
    clf.fit(X_train, y_train)
    trees.append(clf)

# using 5 fold Cross-validation for each tree, trains on 4 tests on 1 and rotates
cv_scores = [np.mean(cross_val_score(tree, X_train, y_train, cv=5)) for tree in trees]

# CV accuracy vs alpha
plt.figure(figsize=(10, 6))
plt.plot(ccp_alphas, cv_scores, marker='o')
plt.xlabel("ccp_alpha")
plt.ylabel("Cross-validated Accuracy")
plt.title("Cross-validation Accuracy vs CCP Alpha (Pruning Strength)")
plt.grid(True)
plt.show()

# Get the best alpha (with highest mean CV score)
optimal_alpha = ccp_alphas[np.argmax(cv_scores)]
print(f"Optimal ccp_alpha: {optimal_alpha:.5f}")

Optimal ccp_alpha: 0.00313

An unpruned decision tree fits the training data very well, often leading to overfitting by memorizing noise along with relevant patterns. In contrast, a pruned tree has a higher training error since it is simpler, but this simplification improves its generalization ability and reduces overfitting risk. Consequently, while the pruned tree may perform worse on training data, it can achieve better or comparable results on test data, which is what truly matters.
