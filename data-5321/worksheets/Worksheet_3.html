from sklearn.model_selection import GridSearchCV
from sklearn.compose import ColumnTransformer
from sklearn.pipeline import Pipeline
# GridSearchCV: For tuning hyperparameters (C in this case) using cross-validation
# Grid search is used to find the best hyperparameter(s) for your model, in this case, the cost parameter C for the Support Vector Classifier.
# ColumnTransformer: To apply preprocessing (like encoding) to specific columns
# Pipeline: To chain preprocessing + model steps into one unit
# A Pipeline in scikit-learn is used to streamline and safeguard your machine learning workflow.

# Converting columns like 'Yes'/'No', or those with few unique values, into 'object' dtype
#Ensuring categorical features are detected and encoded properly
for col in X_train.columns:
    if X_train[col].dtype == 'bool' or X_train[col].nunique() < 10 and X_train[col].dtype != 'float64':
        X_train[col] = X_train[col].astype('object')
        X_test[col] = X_test[col].astype('object')

# Label encode the target variable
#This is needed because SVC doesn’t accept string targets
label_encoder = LabelEncoder()
y_train = label_encoder.fit_transform(y_train_raw)  # CH/MM -> 0/1
y_test = label_encoder.transform(y_test_raw)

# Automatically detects columns that are categorical so they can be passed to OneHotEncoder
cat_cols = X_train.select_dtypes(include='object').columns.tolist()
preprocessor = ColumnTransformer(transformers=[('cat', OneHotEncoder(drop='first', handle_unknown='ignore'), cat_cols)],
    remainder='passthrough'  # Leave numeric columns as-is
)
#remainder='passthrough': numeric columns are left untouched

# Build the pipeline, combines preprocessing and the SVM model into a single, reusable object
#Ensures that every CV fold gets consistent preprocessing
pipeline = Pipeline(steps=[('preprocess', preprocessor),('svc', SVC(kernel='linear'))])

# Defining grid for C values
param_grid = {'svc__C': [0.01, 0.1, 0.5, 1, 5, 10]}

#Cross-validation, Selects the model that gives the best average accuracy on validation folds
grid_search = GridSearchCV(pipeline, param_grid, cv=5)
grid_search.fit(X_train, y_train)

# STEP 8: Results
print("Best C from cross-validation:", grid_search.best_params_['svc__C'])
print("Best cross-validation score (accuracy):", grid_search.best_score_)

best_model = grid_search.best_estimator_
y_test_pred = best_model.predict(X_test)
test_error = 1 - accuracy_score(y_test, y_test_pred)
print(f"Test Error Rate with best C: {test_error:.4f}")

Best C from cross-validation: 0.5
Best cross-validation score (accuracy): 0.81875
Test Error Rate with best C: 0.1556

from sklearn.preprocessing import StandardScaler

X = auto_cleaned.drop(columns='high_mpg')
y = auto_cleaned['high_mpg']

# Building pipeline with standard scaling + linear SVM
pipeline = Pipeline([('scale', StandardScaler()),('svc', SVC(kernel='linear'))])
# This pipeline does two things,
#Standardizes the features: StandardScaler ensures all features have mean = 0 and std = 1 (important for SVM performance).
#Trains a linear SVM: SVC(kernel='linear') finds a linear boundary to separate high vs low MPG cars.
# SVM is sensitive to the scale of input variables. Without scaling, features like weight (thousands of pounds) would dominate smaller features like acceleration.

param_grid = {'svc__C': [0.01, 0.1, 1, 5, 10]}

grid = GridSearchCV(pipeline, param_grid, cv=5)#Train on 4 parts, validate on 1, repeat 5 times
grid.fit(X, y)
#This avoids overfitting and gives a robust estimate of how well each C value performs

for C, score in zip(grid.cv_results_['param_svc__C'], grid.cv_results_['mean_test_score']):
    print(f"C = {C}: Cross-Validation Error = {1 - score:.4f}")

Explanation:¶

  • The analysis revealed that the lowest cross-validation error occurred with a cost parameter (C) set at 0.01. This finding indicates that a softer margin, which allows for greater flexibility regarding misclassifications, can enhance the model's generalization performance.

  • As the cost parameter increases, the model's tendency to strictly classify the training data leads to a more rigid approach, resulting in higher error rates due to overfitting.

  • These findings underscore a significant principle in model selection: simpler models with wider margins often outperform more complex ones, especially when the relationship between features and the target variable is not excessively intricate. Consequently, a low cost value of C = 0.01 emerges as the most effective configuration for this particular problem.

X = auto_cleaned[['horsepower', 'weight']].values

X_mean = X.mean(axis=0)
X_std = X.std(axis=0) #Standardizes both features (zero mean, unit variance)
X_scaled = (X - X_mean) / X_std

svc = SVC(kernel='linear', C=0.01)
svc.fit(X_scaled, y) #This favors a wider margin and allows some misclassification

# meshgrid to visualize decision boundary
h = 0.02
x_min, x_max = X_scaled[:, 0].min() - 1, X_scaled[:, 0].max() + 1
y_min, y_max = X_scaled[:, 1].min() - 1, X_scaled[:, 1].max() + 1
xx, yy = np.meshgrid(np.arange(x_min, x_max, h), np.arange(y_min, y_max, h))
#Generates a dense grid of points across the plot area
# Prediction on grid

Z = svc.predict(grid_points).reshape(xx.shape)
fig, ax = subplots(figsize=(8, 6))
cmap = cm.coolwarm

# Contour plot (decision boundary)

Explanation:¶

In this analysis, a linear Support Vector Classifier (SVC) was trained using an optimal cost value of C = 0.01 on two numeric predictors from the Auto dataset: horsepower and weight. This model aimed to classify cars as having high or low gas mileage (MPG), based on whether their MPG was above or below the median.

To visualize the model's performance, I standardized both features and plotted the decision boundary using a mesh grid. The resulting plot illustrates the SVM's separation of the feature space.

Plot Shows:

  • The red and blue shaded areas indicate high MPG (1) and low MPG (0) classifications.
  • Data points are represented by colored dots according to their actual MPG labels.
  • Black borders denote support vectors near the margin, with a linear decision boundary reflecting the use of a linear kernel.

Interpret: Cars with lower horsepower and weight are more likely to be classified in the high MPG region (red), while heavier and more powerful cars typically fall into the low MPG category (blue). This visualization only incorporates two features, whereas the full dataset has additional variables that can affect classification. Thus, the decision boundary in this 2D space does not fully represent the model's complexity in higher dimensions.

This plot serves as an informative visualization of how a linear SVM classifies data with two predictors, providing insights into margin-based classification. However, it should not be solely relied upon to assess overall model performance or complexity with more features.
