  1. Produce a pruned tree corresponding to the optimal tree size obtained using cross-validation. If cross-validation does not lead to selection of a pruned tree, then create a pruned tree with five terminal nodes.
max_size <- max(cv_oj$size)

if (optimal_size < max_size) {
  pruned_tree <- prune.misclass(tree_OJ, best = optimal_size)
  cat("Pruned to optimal size from cross-validation:", optimal_size, "\n")
} else {
  # Cross-validation suggests no pruning; prune to 5 nodes manually
  pruned_tree <- prune.misclass(tree_OJ, best = 5)
  cat("Cross-validation did not suggest pruning, so pruned to 5 terminal nodes.\n")
}
## Cross-validation did not suggest pruning, so pruned to 5 terminal nodes.
plot(pruned_tree)
text(pruned_tree, pretty = 0)

Exercise 2: Decision Trees for Regression

In the lab, a classification tree was applied to the Carseats data set after converting Sales into a qualitative response variable. Now we will seek to predict Sales using regression trees and related approaches, treating the response as a quantitative variable.

  1. Split the data set into a training set and a test set.
library(ISLR2)
data(Carseats)
set.seed(123)

train_ind <- sample(1:nrow(Carseats), nrow(Carseats) / 2)
train <- Carseats[train_ind, ]
test <- Carseats[-train_ind, ]

cat("Training set size:", nrow(train), "\n")
## Training set size: 200
cat("Test set size:", nrow(test))
## Test set size: 200
  1. Fit a regression tree to the training set. Plot the tree, and interpret the results. What test MSE do you obtain?
library(tree)

reg <- tree(Sales ~ ., data = train)
summary(reg)
