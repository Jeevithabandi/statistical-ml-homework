# Statistical Machine Learning — Homework

My homework and worksheets from two courses in my MS in Data Science at
Seattle University. Mostly my own work, except where I say otherwise.

## DATA 5321 — Statistical Machine Learning 1 (Winter 2025)

Worksheets and assignments in R and Python, following the ISLR/ISLP material:
decision trees and ensembles, support vector machines and classifiers, neural
networks, PCA, and clustering, plus written assignments on GAMs and related
methods (including a Wage-dataset analysis with non-linear fitting).

- `data-5321/worksheets/` — weekly worksheets (R and Python)
- `data-5321/assignments/` — assignments 1–10: R code (`.R`) and rendered
  write-ups (`.pdf` / `.docx`)

A few of the rendered write-ups aren't here. Two of them — my Assignment 1
write-ups for questions 8 and 9, with the R code and results — had my
laptop's file paths baked into the output (my Windows username and OneDrive
folders), so I left them out. Same for a PCA worksheet in the worksheets
folder: it was an exercise on the Yale Faces dataset, which is 165 grayscale
photos of 15 people's faces. The rendered notebook had the face images
embedded in it along with my file paths, so that one stays out entirely. What
it covered: eigenfaces, keeping the top principal components, and rebuilding
faces from just a few components. The R code for the other assignments is all
here, and it doesn't have any of that in it.

## DATA 5322 — Statistical Machine Learning 2 (Spring 2025)

- `data-5322/summaries/` — short write-ups I made while studying: tree-based
  methods, deep learning, unsupervised learning, and a decision-tree summary map
- `data-5322/youth-drug-use/` — my first homework: modeling youth drug use
  with the National Survey on Drug Use and Health (NSDUH) data. The R Markdown
  source, the report, and the slides are here. The data itself is
  de-identified survey data on a sensitive topic, and it was supplied by the
  course, so it is not in this repo — the write-up describes the analysis in
  aggregate only.
- `data-5322/hawks/` — a short NumPy/pandas exercise with the hawks dataset
- `data-5322/group-work-suicide-rates/` — my write-up of our group final
  project: predicting gender-specific global suicide rates, with David Stanko,
  Yeabsera Gente, and Michelle Rhea Sathish. I contributed to most parts of
  it. We used country-level data from the Institute for Health Metrics and
  Evaluation — suicide rates, mental health prevalence, and GDP — and modeled
  them with PCA, decision trees, and ensembles. The group's report and slides
  were our shared documents, so they're not here; my write-up covers the
  project and my part in it. The project code lives in my teammates'
  repositories.
